# Dushi Papiamentu

Papiamentu-leerapp (Curaçaose variant) voor sprekers van Nederlands, Spaans en Portugees.
Statische site: geen build nodig.

## Deployen
1. Maak een nieuwe GitHub-repo en upload deze bestanden (index.html, app.js, data.js, style.css).
2. In Vercel: **Add New → Project → Import** de repo. Framework preset: **Other**. Geen build command. Deploy.

## Inhoud aanpassen
Alle lessen, klankregels, valse vrienden en grammatica staan in `data.js`.
